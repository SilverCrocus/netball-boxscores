These 4:3 SVG flags are vendored from [flag-icons](https://github.com/lipis/flag-icons) version 7.5.0.

- Only the 12 flags required for the Glasgow 2026 netball field are included.

Northern Ireland uses flag-icons' `gb-nir.svg` as a recognizable Commonwealth sporting identifier. Northern Ireland has no current official governmental flag and no dedicated Unicode subdivision flag.
